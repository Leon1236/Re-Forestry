# ARB-11.8g notes — Forestry wood boats + chest boats

**Date:** 2026-07-25

## What landed

- Shared entity types `reforestry:boat` / `reforestry:chest_boat` with synched `ForestryWoodType` (CE pattern).
- `ForestryBoat` extends vanilla `Boat`; `ForestryChestBoat` extends `AbstractChestBoat` (26.2 sibling hierarchy — not CE’s chest-extends-boat).
- Drop item via `Supplier` holder (`ForestryBoat.DropItem`) because `AbstractBoat.getDropItem()` is `final` and `this` cannot be referenced before `super()`.
- 43 boat + 43 chest boat items (`reforestry:<wood>_boat` / `_chest_boat`), dispenser behaviors, creative tab entries.
- Client: `ForestryBoatRenderer` + shared model layers; textures already present under `textures/entity/boat/` and `chest_boat/`.
- Assets generated by `tools/generate_boat_assets.py` (item models, item defs, recipes, `minecraft:boats` / `chest_boats` tags).
- Chest inventory: vanilla `AbstractChestBoat` / `ContainerEntity` (no Forge capability; Fabric transfer not wired).

## 26.2 vs CE

| CE 1.20 | Re-Forestry 26.2 |
|---|---|
| `extends Boat` + NBT CompoundTag | `ValueInput` / `ValueOutput`; `defineSynchedData(Builder)` |
| Override `getDropItem()` | `final` — use `Supplier` holder |
| Fall damage → planks/sticks | Vanilla `checkFallDamage` no longer breaks boats |
| Forge `InvWrapper` on chest boat | Skip; vanilla container screen is enough |
