# A3 — Assembly kits

## API
**No CE API** — `ItemAssemblyKit` is internal only.

## Behavior (CE)
Right-click: consume 1 kit, spawn `ItemEntity` with full A2 tool at the player. Stack size 24.

## Ids (keep CE asymmetry)
`kit_pickaxe`, `kit_shovel`, `axe_kit`, `sword_kit`, `hoe_kit`

## Recipes
- Shapeless: bronze tool + carton → kit
- Carpenter (time 20, box = carton): bronze + stick tool pattern → kit

## Tags
CE only lists kits in backpack allow-lists (Track B). No other item tags for A3.
